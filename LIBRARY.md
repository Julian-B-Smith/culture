[L0002] The golden traces are blind to float32 slips in hidden state | candidate | added: 2026-10-02 | tags: parity-and-float | lesson: goldens hash only alive/tier, so a rounding difference in pressure/wall/resist can run for thousands of generations without flipping a cell. A port change that touches float32 storage must be checked with the deep-state gate (cpp_deep), not just compare.js. | evidence: 2026-10-02 plants — `0.8f` in pressure decay passed all four goldens (14,000 gens) but cpp_deep failed at gen 866; float-only `res*forget` failed only stress-seed-4 at gen 4342. | falsifier: a float32 slip that cpp_deep misses but a golden catches, or golden format changes that hash hidden state. | supersedes: —

[L0003] A 440×280 bench is only honest once several tiers exist | candidate | added: 2026-10-02 | tags: perf | lesson: step cost grows with tier count (feed checks, mixed neighborhoods, pressure), so a short bench at one tier understates it. Bench 4,000 steps per seed, seeds 1–3, Release only. | evidence: before tuning, 500 steps gave 3.06 ms at 1 tier; 4,000 steps gave 4.08–4.74 ms at 5–8 tiers. | falsifier: a seed where step cost falls as tiers accumulate. | supersedes: —

[L0004] V8's Math.sin/cos is fdlibm, compiled with FMA on Apple Silicon — the JS reference's trig depends on the machine | candidate | added: 2026-10-02 | tags: parity-and-float | lesson: to match V8 trig bit for bit, run fdlibm with clang's contractions written as std::fma (core/src/fdlibm.hpp); plain fdlibm matches only x86-64 builds, and the platform libm matches neither. Any other V8 libm function the core comes to depend on (log2, pow, exp…) should be suspected of the same split: measure it against node on BOTH flavors before trusting it. | evidence: 2026-10-02, 2.24M arguments: libm vs V8 101,600 diffs; plain fdlibm 12,517; fdlibm with -ffp-contract=on 0; explicit-fma port 0 at -O2 and -O0 (D-027). node 24.10 exports v8::base::ieee754::cos/sin, no libm_* trig. | falsifier: an arm64 node whose Math.sin matches plain fdlibm, or a V8 built with libm trig (V8_USE_LIBM_TRIG_FUNCTIONS) — tests/trig_flavor.js would then report "plain" or "unknown". | supersedes: —
